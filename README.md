## 关于我

我喜欢写离真实系统更近的软件：模型网关、RAG 检索链路、Agent 工作空间、
分布式后端服务、命令行工具，以及一些为了理解底层机制而从零实现的 Rust 项目。

我的本地工作区里既有偏工程落地的应用，也有学习型项目：Spring Boot 服务、
React / Tauri 前端、LangGraph Agent、Rust 框架实验、C++ Windows 工具和 Python AI 服务。
